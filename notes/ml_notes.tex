\section{Mathematical Concepts}

\subsection{Eigenvectors and Eigenvalues}
Let $A = [a_{ij}]_{n \times n}$. Consider the homogeneous
system of equation,

\[
    AX = \lambda X
\]

Or,

\[
    (A - \lambda I) = 0
\]

Which gives the \emph{characteristic equation}. Upon solving,
the values are $\lambda$ are found, which are the eigen values.

Put these $\lambda$ in the first equation and solve for $X$
to find the corresponding eigenvector.

\subsection{Singular Value Decomposition (SVD)}
It is a way of computing $U$, $\Sigma$, $V$, where $A = U\Sigma V^{T}$

\emph{Step 1 - $V$}:
\begin{itemize}
    \item Find the value of $A^TA$
    \item Find eigen values \& eigen vectors of $A^TA$.
        Write the eigen values in descending order
        ($\lambda_1 > \lambda_2 ...$) 
    \item Write the corresponding normalized eigen vectors
        in columns of a matrix
    \item This matrix is $V$.
\end{itemize}

\emph{Step 2 - $\Sigma$}:
\begin{itemize}
    \item Order of $\Sigma$ = Order of $A$.
    \item $\sigma_1 = \sqrt{\lambda_1}$ and $\sigma_2 = \sqrt{\lambda_2}$.
    \item Rank of $\Sigma$ = Number of non zero eigen values
    \item
        \[
            \Sigma =
                \begin{bmatrix}
                    \Sigma_1 & 0 \\
                    0 & 0
                \end{bmatrix}
        \]
        Where, $\Sigma_1$ is a diagonal matrix whose diagonal entries are
        $\sigma_1$ and $\sigma_2$. The zeros are added around $\Sigma_1$
        to make the Order of $\Sigma$ = Order of $A$.

\end{itemize}

\emph{Step 3 - $U$}:
\begin{itemize}
    \item Find $AA^T$.
    \item Find eigenvalues ($\lambda_1 > \lambda_2 ...$) and
        eigenvectors (normalized) of $AA^T$.
    \item $U$ is the matrix found by appending the eigen vectors one after
        the other.
\end{itemize}
